# v2.0

2.0 is a new scope, not a better 1.0.

## Done when
A reviewer can see which findings came from source and which came from an artifact, and the published corpus supports both claims.

- Source score and artifact score are separate.
- Each CBOM component has `qci:provenance`.
- `tests/corpus/artifacts` is the artifact claim.
- Packed code and deploy-time values are still out.

2.0 is justified by a named need. It is not the next release after 1.1 by default.
