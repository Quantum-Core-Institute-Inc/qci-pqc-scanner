# QCI Crypto Inventory 2.3.4.6

## What changed
- Dependency versions are read from lockfiles. A range marker is stripped.
- LMS and XMSS are detected. Stateful hash-based signatures, used for firmware.
- The report states key establishment and signatures, and says when the two roles differ.
- A waiver key is family, path, and parameter. A valid waiver matches.
- A resolved constant and an enum constructor are uses.
- Config lines: ssh-rsa, default_md = sha1, ike=3des.

## Limit
A name assembled at runtime is out of scope. Joined fragments, base64, character codes.
